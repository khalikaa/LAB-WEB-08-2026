# Portofolio Fajrel

Website profil satu halaman (SPA) dengan React, Vite, dan Tailwind CSS.

## Menjalankan

    npm install
    npm run dev

Cek kualitas kode: `npm run lint` dan `npm run build`.

## Mengganti foto

- Foto profil: timpa `public/foto-profil.jpg`
- Galeri: timpa `src/assets/gallery/foto-1.jpg` sampai `foto-5.jpg`
- Judul dan keterangan foto ada di array `daftarFoto` pada `src/components/Gallery.jsx`
